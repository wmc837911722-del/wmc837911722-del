## 我能帮助你做什么

### 业务诊断与方案共创

- 梳理业务目标、用户流程、数据条件与现实约束
- 识别真正值得投入的 AI 场景与优先级
- 输出解决方案架构、实施路径和阶段目标建议

### AI 原型与智能体验证

- 构建 AI 工作流、智能体或产品原型
- 验证模型、工具调用、业务数据接入和交互流程
- 设计效果评测、安全边界与失败场景处理方式

### 生产集成与工程交付

- 开发 Web 产品、内部业务工具和前后端功能
- 集成模型、知识库、权限、数据与现有企业系统
- 完成测试、部署、日志、监控和交付文档

### 落地采用与持续迭代

- 根据真实使用反馈优化产品、流程和模型能力
- 建立评测、复盘与版本迭代机制
- 完成使用说明、运维文档和团队交接

## 适合找我的情况

- 有 AI 想法，但还不知道先做哪个场景、如何验证价值
- 已经有演示原型，但卡在数据、权限、系统集成或上线
- 希望给现有 SaaS、内部系统或业务流程增加 AI 能力
- 需要一个能够同时理解业务、产品和工程的交付角色
- 希望先用小范围验证控制风险，再决定是否扩大投入

## 我的工作方法

`DISCOVER → PROTOTYPE → DEPLOY → ITERATE`

1. 进入业务现场，定义问题与成功标准
2. 快速构建原型，验证最关键的不确定性
3. 接入真实系统，完成稳定的工程交付
4. 根据使用结果持续优化，并沉淀可交接能力
